# Методичка курса «Разработка сайтов и веб-приложений» от команды IT-ПАРКа

Краткий учебный справочник: от устройства Web, HTML и CSS до JavaScript, React, TypeScript, тестирования, производительности и дополнительного backend на PHP/Laravel.

Методичка сопровождает занятия и помогает быстро повторить тему, восстановить понимание, увидеть небольшой рабочий пример, проверить себя практикой и подготовиться к техническому собеседованию.

Принцип работы: **понять идею → увидеть пример → воспроизвести самостоятельно → проверить себя**. На статью и практику обычно достаточно 15–30 минут.

## Локальный запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements-docs.txt
mkdocs serve
```

Откройте `http://127.0.0.1:8000`.

## Проверка перед публикацией

```bash
mkdocs build --strict
```

Сайт автоматически публикуется в GitHub Pages после отправки изменений в ветку `main`.
