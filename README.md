# Методичка 14 потока по веб-разработке

50 коротких глав по программе: HTML, CSS, JavaScript, React, TypeScript, тестирование, архитектура и работа в IT. Дополнительный backend-маршрут охватывает PHP, MySQL и Laravel. Отдельный раздел готовит к техническому интервью по всем темам методички.

Материалы разделяют темы, подтвержденные исходниками 14 потока, и темы, включенные по полной программе курса.

## Локальный запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements-docs.txt
mkdocs serve
```

Откройте `http://127.0.0.1:8000`.

## Проверка перед публикацией

```bash
mkdocs build --strict
```

Сайт автоматически публикуется в GitHub Pages после отправки изменений в ветку `main`.
