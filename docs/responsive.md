# 4. Адаптивная верстка

<p class="reading-time">Чтение: 5 минут</p>

Адаптивная страница меняет компоновку, размеры и поведение под доступное пространство, а не под названия конкретных телефонов.

## База

```css
.container {
  width: min(100% - 32px, 1180px);
  margin-inline: auto;
}

.gallery {
  display: grid;
  grid-template-columns: repeat(3, minmax(0, 1fr));
  gap: clamp(16px, 2vw, 28px);
}

img {
  display: block;
  max-width: 100%;
  height: auto;
}
```

Относительные размеры, `min()`, `max()` и `clamp()` уменьшают число резких переключений.

## Медиа-запрос

```css
@media (max-width: 768px) {
  .gallery {
    grid-template-columns: 1fr;
  }
}
```

Точка перелома нужна там, где макет начинает ломаться: текст зажимается, элементы не помещаются или нарушается иерархия.

## Что проверять

- ширины от 320px до большого монитора;
- увеличение текста и масштаб страницы;
- клавиатурный фокус;
- длинные заголовки и реальные данные;
- отсутствие горизонтальной прокрутки;
- размеры интерактивных элементов.

!!! warning "Не прячьте проблему"
    `overflow-x: hidden` может скрыть ошибку раскладки. Найдите элемент, который шире окна, и исправьте его размер или позиционирование.

## Где это было

В материалах потока адаптивность видна в макетах магазина велосипедов, карточек отзывов, портфолио, `Северяночке`, `Desserts` и `GitHub User Finder`.

## Мини-практика

Проверьте один из своих макетов на ширинах 360px, 768px и 1280px. Запишите три изменения компоновки, а не только три уменьшения шрифта.
