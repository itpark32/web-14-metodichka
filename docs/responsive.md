# 9. Адаптивная верстка

<p class="reading-time">Чтение: 8 минут</p>

Адаптивная страница меняет компоновку, размеры и поведение под доступное пространство, а не под названия конкретных телефонов.

!!! abstract "Фокус"
    - **Нужно знать:** viewport, гибкие размеры, медиазапросы, адаптивные изображения.
    - **Часто в работе:** `clamp`, проверка длинного текста, `prefers-reduced-motion`.
    - **Достаточно узнавать:** медиазапросы по редким возможностям устройства.

## База

```css
.container {
  width: min(100% - 32px, 1180px);
  margin-inline: auto;
}

.gallery {
  display: grid;
  grid-template-columns: repeat(3, minmax(0, 1fr));
  gap: clamp(16px, 2vw, 28px);
}

img {
  display: block;
  max-width: 100%;
  height: auto;
}
```

Относительные размеры, `min()`, `max()` и `clamp()` уменьшают число резких переключений.

## Медиа-запрос

```css
@media (max-width: 768px) {
  .gallery {
    grid-template-columns: 1fr;
  }
}
```

Подход mobile first начинает с узкого экрана и расширяет макет:

```css
.gallery { grid-template-columns: 1fr; }

@media (min-width: 48rem) {
  .gallery { grid-template-columns: repeat(3, 1fr); }
}
```

Оба подхода допустимы. Важнее, чтобы команда использовала понятную систему, а переключение происходило там, где ломается контент.

Точка перелома нужна там, где макет начинает ломаться: текст зажимается, элементы не помещаются или нарушается иерархия.

## Что проверять

- ширины от 320px до большого монитора;
- увеличение текста и масштаб страницы;
- клавиатурный фокус;
- длинные заголовки и реальные данные;
- отсутствие горизонтальной прокрутки;
- размеры интерактивных элементов.

!!! warning "Не прячьте проблему"
    `overflow-x: hidden` может скрыть ошибку раскладки. Найдите элемент, который шире окна, и исправьте его размер или позиционирование.

## Как ответить на интервью

> Адаптивность строится от содержимого: использую гибкий контейнер и сетку, ограничиваю изображения, а медиазапрос добавляю в точке, где текущая компоновка перестает работать. Проверяю не только три популярных ширины, но и промежуточные значения, масштаб текста и длинные данные.

## Где это было

В проектах потока адаптивность применялась в макетах «Северяночка», Clean Portfolio и учебных верстках.

## Мини-практика

Проверьте один из своих макетов на ширинах 360px, 768px и 1280px. Запишите три изменения компоновки, а не только три уменьшения шрифта.
