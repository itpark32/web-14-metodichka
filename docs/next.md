# Карта полной программы

<p class="reading-time">5 модулей и выпускной проект</p>

Карта помогает увидеть курс целиком и выбрать главу для повторения. Исходники подтверждают практику от верстки до старта React. Остальные темы включены по программе и вашему подтверждению о полном прохождении курса.

## Верстка сайтов

HTML, CSS, семантика, формы, медиа, SVG, доступность, Flexbox, Grid, адаптивность, Bootstrap, Figma, БЭМ, SCSS, Git и публикация.

## JavaScript

Типы данных, алгоритмы, коллекции, функции, области видимости, контекст, ООП, DOM, BOM, события, формы, хранение данных, асинхронность, HTTP, REST API, модули и SPA.

## React и TypeScript

Компоненты, props, state, хуки, Context, Redux Toolkit, React Router, формы, авторизация, Fetch/Axios, React Query, TypeScript, тестирование и производительность.

## Подготовка к работе

Жизненный цикл продукта, Agile, Scrum, Kanban, роли в команде, code review, резюме, GitHub, портфолио, вакансии, тестовые задания, HR-этап и техническое собеседование.

## Дополнительный backend

PHP, MySQL, SQL, HTTP, сессии, cookie, ООП, MVC, Composer, Laravel, Eloquent ORM, Blade, REST API, аутентификация и базовая безопасность.

## Выпускной проект

Хороший итоговый проект демонстрирует не количество библиотек, а законченную пользовательскую задачу, понятную архитектуру, обработку ошибок, тесты и доступный интерфейс.
