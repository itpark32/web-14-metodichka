# 5. БЭМ и SCSS

<p class="reading-time">Чтение: 5 минут</p>

БЭМ дает классам предсказуемые имена. SCSS добавляет переменные, вложенность и примеси, а затем компилируется в обычный CSS.

## Блок, элемент, модификатор

```html
<article class="card card--featured">
  <h2 class="card__title">Название</h2>
  <p class="card__text">Описание</p>
</article>
```

- `card` может существовать самостоятельно;
- `card__title` имеет смысл внутри блока;
- `card--featured` меняет состояние или вариант блока.

Не отражайте в имени всю структуру DOM: `card__body__title` связывает CSS с текущей вложенностью.

## SCSS

```scss
$accent: #174c43;
$radius: 12px;

@mixin focus-ring {
  outline: 3px solid rgba($accent, 0.35);
  outline-offset: 3px;
}

.card {
  border-radius: $radius;

  &__title {
    color: $accent;
  }

  &:focus-within {
    @include focus-ring;
  }
}
```

Вложенность должна оставаться неглубокой. SCSS помогает организовать код, но не исправляет плохую структуру селекторов.

## Где это было

Рефакторинг в БЭМ виден в историях уроков 11-21, а переменные и `@mixin` использованы в учебном SCSS-проекте потока.

## Мини-практика

Выберите секцию старого макета, переименуйте классы по БЭМ и вынесите повторяющиеся цвет, радиус и отступ в SCSS-переменные.
