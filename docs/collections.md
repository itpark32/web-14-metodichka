# Коллекции: как выбрать инструмент

<p class="reading-time">Чтение: 4 минуты</p>

!!! abstract "Фокус"
    - **Нужно знать:** чем строка, массив и объект отличаются друг от друга и какую структуру выбрать для задачи.
    - **Часто в работе:** преобразование данных через `JSON.parse`, `filter`, `map` и `join`.
    - **Достаточно узнавать:** редкие методы коллекций и детали их внутренней реализации.

Коллекцию выбирают по операциям: список важен для порядка, объект объединяет свойства сущности, Map связывает ключи и значения, Set хранит уникальные значения.

    Запоминайте группы задач: проверка, поиск, извлечение, преобразование и перебор. Сигнатуру редкого метода нормально проверить в документации.

## Базовый маршрут данных

```js
const response = '[{"title":"CSS","done":true}]';
const tasks = JSON.parse(response);      // строка -> массив объектов
const completed = tasks.filter(item => item.done);
const titles = completed.map(item => item.title);
const label = titles.join(", ");           // массив -> строка
```

На практике структуры постоянно переходят одна в другую. Важно понимать, какой тип получен на каждом шаге и меняет ли операция исходное значение.

## Map и Set

```js
const tags = ["js", "react", "js"];
const uniqueTags = [...new Set(tags)]; // ["js", "react"]

const usersById = new Map();
usersById.set(42, { id: 42, name: "Anna" });
console.log(usersById.get(42)); // { id: 42, name: "Anna" }
```

Set удаляет повторяющиеся значения, сохраняя порядок добавления. Map дает явные `set`, `get`, `has`, `delete` и принимает ключи любого типа. `get` отсутствующего ключа вернет `undefined`. Два разных объекта с одинаковыми полями не считаются одним элементом Set: сравнивается идентичность.

## Когда использовать

Массив подходит для сортировки каталога, объект — для профиля, Map — для поиска профиля по ключу, Set — для выбранных уникальных тегов. JSON напрямую не сохраняет Map/Set как обычные массивы: перед сериализацией преобразуйте их.

## Частые ошибки

- Путать уникальность объектов с равенством их полей.
- Использовать объект как список, когда важен порядок и методы массива.
