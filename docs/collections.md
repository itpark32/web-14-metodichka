# 10. Строки, массивы и объекты

<p class="reading-time">Чтение: 8 минут</p>

Строка хранит последовательность символов, массив упорядочивает значения, объект связывает ключи со значениями.

## Строки

```js
const source = "  JavaScript Basics  ";
const title = source.trim().toLowerCase();

title.includes("script"); // true
title.split(" ");         // ["javascript", "basics"]
```

Строки неизменяемы: методы возвращают новое значение. Часто используются `trim`, `includes`, `startsWith`, `slice`, `split`, `replace`.

## Массивы

```js
const prices = [120, 350, 80];

prices.push(500);                       // меняет исходный массив
const discounted = prices.map(p => p * 0.9);
const affordable = prices.filter(p => p < 300);
const total = prices.reduce((sum, p) => sum + p, 0);
```

- `forEach` выполняет действие и возвращает `undefined`;
- `map` сохраняет длину и преобразует каждый элемент;
- `filter` оставляет подходящие элементы;
- `find` возвращает первый элемент или `undefined`;
- `some` и `every` отвечают на логический вопрос.

## Объекты и ссылки

```js
const product = { id: 7, title: "Кофе", price: 450 };
const copy = { ...product, price: 390 };

Object.keys(product);   // ключи
Object.values(product); // значения
```

Объекты сравниваются по ссылке. `{}` не равно `{}`, потому что это два разных объекта. Spread создает поверхностную копию: вложенные объекты по-прежнему могут иметь общую ссылку.

!!! warning "Мутация"
    `push`, `pop`, `splice`, `sort` меняют массив. `map`, `filter`, `slice`, `concat`, `toSorted` возвращают новый. Перед выбором метода решите, допустимо ли менять исходные данные.

## Мини-практика

Из массива товаров получите новый массив названий товаров дешевле 1000 рублей и посчитайте их общую цену. Исходный массив не изменяйте.
