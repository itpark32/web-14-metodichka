# 12. Регулярные выражения

<p class="reading-time">Чтение: 6 минут</p>

Регулярное выражение описывает шаблон текста. Оно подходит для поиска, замены и проверки формата, но не заменяет полноценный разбор сложного языка.

## Синтаксис

```js
const emailPattern = /^[a-z0-9._-]+@[a-z0-9.-]+\.[a-z]{2,}$/i;
emailPattern.test("student@example.com"); // true
```

- `^` и `$` обозначают начало и конец строки;
- `[]` задает набор символов;
- `\d`, `\s`, `\w` обозначают цифру, пробельный и буквенно-цифровой символ;
- `+`, `*`, `?`, `{2,4}` задают количество;
- скобки создают группу;
- флаги `i`, `g`, `m` меняют режим поиска.

## Методы

```js
const text = "Заказы: A-15, B-27";

/[A-Z]-\d+/g.test(text);       // true
text.match(/[A-Z]-\d+/g);      // ["A-15", "B-27"]
text.search(/B-\d+/);          // индекс начала
text.replace(/\d+/g, "XX");   // "Заказы: A-XX, B-XX"
```

`test` отвечает `true` или `false`. `match` возвращает совпадения, `search` индекс, `replace` новую строку.

!!! warning "Валидация email"
    Регулярное выражение проверяет только форму строки. Реальное существование адреса подтверждается письмом, а сервер все равно обязан повторить проверку входных данных.
