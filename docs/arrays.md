# 21. Массивы

<p class="reading-time">Чтение: 10 минут</p>

Массив хранит упорядоченную последовательность. Перед выбором метода задайте два вопроса: нужен ли новый массив и можно ли менять исходный.

!!! abstract "Фокус"
    - **Нужно знать:** индексы, `push`, `pop`, `slice`, `splice`, `map`, `filter`, `find`.
    - **Часто в работе:** `some`, `every`, `reduce`, `sort`, spread.
    - **Достаточно узнавать:** `flat`, `flatMap`, новые немутирующие варианты вроде `toSorted`.

## Добавление и удаление

```js
const topics = ["HTML", "CSS"];

topics.push("JavaScript"); // добавляет в конец, возвращает новую длину
topics.pop();              // удаляет с конца, возвращает элемент
topics.unshift("Git");    // добавляет в начало
topics.shift();            // удаляет с начала
```

Все четыре метода меняют исходный массив. Операции в начале обычно дороже, потому что остальные индексы сдвигаются.

## `slice` и `splice`

```js
const values = [10, 20, 30, 40];

values.slice(1, 3); // [20, 30], исходный массив не меняется
values.splice(1, 2); // [20, 30], исходный стал [10, 40]
```

Созвучные имена скрывают разное поведение. `slice` копирует диапазон. `splice` меняет массив: удаляет, вставляет или заменяет элементы.

## Перебор и преобразование

```js
const products = [
  { title: "Книга", price: 700, available: true },
  { title: "Курс", price: 2500, available: false },
  { title: "Билет", price: 900, available: true },
];

const titles = products.map(product => product.title);
const available = products.filter(product => product.available);
const firstExpensive = products.find(product => product.price > 800);
```

- `forEach` выполняет действие и возвращает `undefined`;
- `map` возвращает массив той же длины;
- `filter` возвращает от нуля до исходного количества элементов;
- `find` возвращает первый элемент или `undefined`;
- `findIndex` возвращает индекс или `-1`.

!!! warning "Ловушка: забытый return"
    При фигурных скобках стрелочной функции нужен явный `return`: `items.map(item => { return item.id; })`. Без него массив заполнится `undefined`.

## Проверки `some` и `every`

```js
products.some(product => product.available);       // хотя бы один
products.every(product => product.price > 0);      // каждый
products.includes(products[0]);                    // содержит это значение или ссылку
```

`some` и `every` прекращают перебор, когда ответ уже известен. Это точнее по смыслу, чем ручной флаг внутри `forEach`.

## `reduce`

```js
const total = products.reduce(
  (sum, product) => sum + product.price,
  0
);
```

Первый аргумент callback является аккумулятором, второй текущим элементом. Начальное значение `0` делает тип результата явным и корректно обрабатывает пустой массив.

Не используйте `reduce` только ради компактности. Если `map`, `filter` или цикл читаются яснее, выбирайте их.

## Сортировка

```js
const numbers = [2, 11, 3];

numbers.sort();              // [11, 2, 3], сравнение как строк
numbers.sort((a, b) => a - b); // [2, 3, 11]
```

`sort` меняет исходный массив. Если данные нужно сохранить:

```js
const sorted = [...numbers].sort((a, b) => a - b);
// или в современном окружении
const sortedModern = numbers.toSorted((a, b) => a - b);
```

Для строк с учетом языка используйте `localeCompare`:

```js
names.sort((a, b) => a.localeCompare(b, "ru"));
```

## Копия не всегда глубокая

```js
const original = [{ title: "HTML" }];
const copy = [...original];
copy[0].title = "CSS";

console.log(original[0].title); // "CSS"
```

Spread создает новый внешний массив, но вложенный объект остается общим. Это поверхностная копия.

## Как ответить на интервью

> Метод массива выбираю по результату и мутации. `map` преобразует каждый элемент, `filter` отбирает, `find` возвращает первый найденный, `some` и `every` проверяют условие. `slice` не мутирует, а `splice` и `sort` мутируют. Для числовой сортировки передаю компаратор.

## Мини-практика

Из массива товаров получите названия трех самых дешевых доступных товаров, не меняя исходный массив. Затем объясните, почему `filter`, копирование, `sort`, `slice` и `map` идут именно в таком порядке.
