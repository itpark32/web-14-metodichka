# 2. CSS и блочная модель

<p class="reading-time">Чтение: 6 минут</p>

CSS выбирает элементы и задает их внешний вид. Итоговый стиль зависит от каскада: важности правила, специфичности селектора и порядка объявления.

## Правило и селектор

```css
.product-card {
  width: 320px;
  padding: 24px;
  border: 1px solid #d7dfdc;
  background-color: #fff;
}

.product-card:hover {
  border-color: #174c43;
}
```

Селектор класса переиспользуется. `id` лучше оставлять для уникальных якорей и связи с JavaScript. Вложенность `.card .title` повышает связанность, поэтому давайте элементам самостоятельные классы.

## Каскад и наследование

- более важный источник побеждает менее важный;
- более специфичный селектор побеждает менее специфичный;
- при равной специфичности срабатывает последнее правило;
- часть свойств текста наследуется, размеры и отступы обычно нет.

Не лечите непонятный каскад множеством `!important`. Сначала найдите правило в DevTools и сравните селекторы.

## Блочная модель

Размер элемента складывается из содержимого, внутренних отступов, границы и внешних отступов.

```css
*,
*::before,
*::after {
  box-sizing: border-box;
}
```

С `border-box` заданная ширина уже включает `padding` и `border`. `margin` отделяет элементы снаружи, `padding` создает пространство внутри фона и границы.

## Поток и позиционирование

- `static` оставляет элемент в обычном потоке;
- `relative` сохраняет место и становится опорой для абсолютного потомка;
- `absolute` исключает элемент из обычного потока;
- `fixed` привязывает к окну;
- `sticky` ведет себя обычно до заданной границы прокрутки.

!!! tip "Как отлаживать размеры"
    Откройте вкладку Computed в DevTools. Она показывает итоговые значения и схему box model, а также правило, которое победило в каскаде.

## Мини-практика

Создайте две одинаковые карточки шириной `300px`. Одной задайте `content-box`, второй `border-box`, обеим добавьте `padding: 20px` и `border: 2px solid`. Сравните фактическую ширину.
