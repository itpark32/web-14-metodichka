# 33. React: состояние и хуки

<p class="reading-time">Чтение: 13 минут</p>

Хуки позволяют функциональному компоненту хранить состояние, выполнять эффекты и переиспользовать связанную логику.

!!! abstract "Фокус"
    - **Нужно знать:** `useState`, `useEffect`, зависимости и правила хуков.
    - **Часто в работе:** `useContext`, `useReducer`, custom hooks и очистка эффекта.
    - **Достаточно узнавать:** `useMemo` и `useCallback` до появления измеренной проблемы.

## `useState`

Состояние хранит данные, изменение которых должно перерисовать интерфейс.

```jsx
const [cart, setCart] = useState([]);

function add(product) {
  setCart((current) => [...current, product]);
}
```

Используйте функциональное обновление, если новое значение зависит от предыдущего. Не мутируйте массивы и объекты состояния.

## Состояние должно быть минимальным

Не храните вычисляемое значение:

```jsx
const total = cart.reduce((sum, item) => sum + item.price, 0);
```

Храните состояние у ближайшего общего родителя компонентов, которым оно нужно. Дублирование одного факта в нескольких состояниях ведет к рассинхронизации.

## `useEffect`

Эффект синхронизирует компонент с внешней системой: сетью, таймером, DOM API, подпиской.

```jsx
useEffect(() => {
  const controller = new AbortController();

  loadProducts(controller.signal).then(setProducts).catch(handleError);

  return () => controller.abort();
}, []);
```

Если значение используется внутри эффекта и может меняться, оно обычно должно быть в массиве зависимостей. Функция очистки удаляет подписку, таймер или отменяет запрос.

## Другие хуки

- `useRef` хранит изменяемое значение без рендера и дает доступ к DOM;
- `useContext` читает данные ближайшего Provider;
- `useReducer` описывает сложные переходы состояния через actions;
- `useMemo` кеширует вычисление;
- `useCallback` кеширует ссылку на функцию;
- пользовательский хук переиспользует логику, но не само состояние.

Мемоизация нужна после измерения, а не на всякий случай.

## Правила хуков

Вызывайте хуки только на верхнем уровне React-компонента или другого хука. Нельзя вызывать их в условиях, циклах и обычных функциях.

!!! warning "Частая ошибка"
    `useEffect` не нужен для вычисления данных из props и state или для обработки клика. Вычисляйте во время рендера, а действие выполняйте в обработчике.

## Как ответить на интервью

> `useState` хранит данные интерфейса, а `useEffect` синхронизирует компонент с внешней системой после рендера. Зависимости перечисляют значения, от которых зависит эффект, а cleanup отменяет подписку или запрос. Хуки вызываются только на верхнем уровне компонента или другого хука.
