# 3. Таблицы, списки, SVG и мультимедиа

<p class="reading-time">Чтение: 10 минут</p>

Контентные элементы выбираются по смыслу данных. Список описывает перечисление, таблица связывает значения по строкам и столбцам, медиа передает изображение, звук или видео.

!!! abstract "Фокус"
    - **Нужно знать:** списки, семантическая таблица, `video`, `iframe`, варианты SVG.
    - **Часто в работе:** `picture`, `source`, подписи и доступные названия.
    - **Достаточно узнавать:** `embed`, сложные таблицы и встроенная SVG-анимация.

## Списки

```html
<ul>
  <li>HTML</li>
  <li>CSS</li>
  <li>JavaScript</li>
</ul>
```

`ul` подходит, когда порядок не влияет на смысл. `ol` нужен последовательности шагов или рейтингу. `dl` связывает термины `dt` с описаниями `dd`.

Не используйте отдельные абзацы с нарисованными дефисами. Настоящий список сообщает структуру вспомогательным технологиям и удобно стилизуется.

## Таблица данных

```html
<table>
  <caption>Расписание консультаций</caption>
  <thead>
    <tr>
      <th scope="col">День</th>
      <th scope="col">Время</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <th scope="row">Среда</th>
      <td>18:30</td>
    </tr>
  </tbody>
</table>
```

- `caption` называет таблицу;
- `tr` задает строку;
- `th` является заголовочной ячейкой;
- `td` является ячейкой данных;
- `scope` связывает заголовок со строкой или столбцом.

Таблицу используйте для данных, где важны обе координаты. Для общей раскладки страницы выбирайте Grid или Flexbox.

!!! warning "Ловушка: таблица для макета"
    Табличная верстка связывает структуру с внешним видом, плохо перестраивается на узком экране и создает неверную семантику. Таблица нужна данным, а не колонкам лендинга.

## Адаптивные изображения

```html
<picture>
  <source srcset="hero.avif" type="image/avif">
  <source srcset="hero.webp" type="image/webp">
  <img src="hero.jpg" alt="Команда обсуждает макет сайта" width="1200" height="800">
</picture>
```

Браузер выбирает первый поддерживаемый источник. Сам `img` остается обязательной запасной версией и носителем `alt`.

## Видео и аудио

```html
<video controls width="720" poster="poster.webp">
  <source src="lesson.webm" type="video/webm">
  <source src="lesson.mp4" type="video/mp4">
  <track kind="captions" src="captions-ru.vtt" srclang="ru" label="Русские субтитры">
  Ваш браузер не поддерживает видео.
</video>
```

`controls` включает нативное управление. Для содержательного видео нужны субтитры. Автовоспроизведение со звуком часто блокируется браузером и мешает пользователю.

## `iframe` и `embed`

```html
<iframe
  src="https://example.com/map"
  title="Карта проезда"
  loading="lazy"
  allowfullscreen>
</iframe>
```

`iframe` встраивает отдельную страницу со своим документом. Дайте фрейму понятный `title`. Не каждый сайт разрешает встраивание. `embed` используется для внешнего содержимого реже и дает меньше контроля.

## SVG

```html
<svg viewBox="0 0 24 24" role="img" aria-labelledby="logo-title">
  <title id="logo-title">Логотип курса</title>
  <circle cx="12" cy="12" r="10" fill="currentColor" />
</svg>
```

Основные способы:

- `<img src="icon.svg" alt="...">` для самостоятельного изображения;
- inline SVG для управления цветом и частями через CSS;
- `background-image` для чисто декоративного фона.

SVG масштабируется без потери качества и подходит иконкам, схемам и логотипам. Фотографию обычно храните в растровом формате.

## Как ответить на интервью

> Список использую для перечисления, таблицу для связанных строк и колонок данных. `caption`, `th` и `scope` делают таблицу понятнее. Видео подключаю через `video` и `source`, внешний документ через `iframe` с названием. SVG вставляю как `img` или inline в зависимости от необходимости управлять его частями.

## Мини-практика

Сверстайте расписание занятий с `caption`, заголовками колонок и строк. Под ним добавьте SVG-иконку и видео с постером и запасным текстом. Проверьте клавиатуру и узкий экран.
