## Маршрут подготовки

| Блок | База | Глубина |
|---|---|---|
| HTML и CSS | семантика, формы, каскад, layout | доступность, адаптивность, производительность |
| JavaScript | типы, функции, коллекции | прототипы, Event Loop, DOM, сеть |
| React | компоненты, props, state | эффекты, reconciliation, hooks, routing |
| TypeScript и state | типы, union, generics | Redux Toolkit, Context, server state |
| Качество | тесты и сборка | архитектура, profiling, code splitting |
| Backend | PHP, SQL, Laravel | HTTP, транзакции, ORM, безопасность |

## Режим на 14 дней

1. Дни 1-2: HTML, CSS и доступность.
2. Дни 3-5: JavaScript и задачи.
3. Дни 6-8: React и маршрутизация.
4. Дни 9-10: TypeScript и управление состоянием.
5. День 11: тестирование, производительность, архитектура.
6. День 12: PHP, SQL, Laravel, безопасность.
7. День 13: рассказ о двух проектах.
8. День 14: пробное интервью без подсказок.
