# Подготовка к собеседованию

<p class="reading-time">Вопросы по всей программе 14 потока, разделенные на короткие блоки</p>

Вопросы сверены с актуальной методичкой и тематикой [my-interview.tech](https://www.my-interview.tech/). Здесь нет случайного каталога редких фактов: каждый блок связан с главами маршрута и проверяет определение, механизм, пример и ограничение.

## Шаблон сильного ответа

<div class="answer-pattern" markdown>

**Определение → механизм → пример → ограничение → выбор.**

«React Query управляет серверным кешем. Query key определяет запись, stale time момент устаревания, invalidation запускает повторную синхронизацию. Для простого одноразового запроса можно обойтись Fetch и эффектом».

</div>

## Как тренироваться

1. Выберите один блок, а не все вопросы сразу.
2. Дайте ответ за 45-90 секунд без подсказки.
3. Покажите пример из 3-8 строк.
4. Назовите частую ошибку или альтернативу.
5. Сверьтесь с ответом и вернитесь к нужной главе.

## Маршрут подготовки

| Блок | Что проверить | Практика |
|---|---|---|
| HTML и CSS | семантика, формы, доступность, Bootstrap, layout и анимации | объяснить верстку по макету |
| JavaScript | типы, числа, коллекции, функции, ошибки и Event Loop | решить задачу у доски |
| Браузер и сеть | DOM, BOM, Storage, HTTP, REST, Git и сборка | разобрать запрос в Network |
| React | JSX, props, state, hooks, формы и routing | разобрать рендер компонента |
| TypeScript и state | типы, generics, DOM, Context, Redux и server state | типизировать состояние запроса |
| Качество | тесты, производительность и архитектура | защитить технический выбор |
| Работа в IT | команда, процессы, проекты, HR и оффер | провести самопрезентацию |
| Backend | PHP, SQL, Laravel и безопасность | спроектировать endpoint |

## Режим на 14 дней

1. Дни 1-2: HTML, CSS, Bootstrap и доступность.
2. Дни 3-5: JavaScript, DOM и задачи.
3. День 6: HTTP, REST, Git и инструменты.
4. Дни 7-8: React, хуки, формы и routing.
5. Дни 9-10: TypeScript и управление состоянием.
6. День 11: тестирование, производительность и архитектура.
7. День 12: PHP, SQL, Laravel и безопасность.
8. День 13: рассказ о двух проектах и HR-блок.
9. День 14: пробное интервью без подсказок.
