# Интервью: TypeScript и состояние

<p class="reading-time">12 ключевых вопросов с короткими ответами</p>

??? question "Чем `type` отличается от `interface`?"
    Оба описывают форму объекта. Interface поддерживает declaration merging и удобно расширяется. Type также описывает union, tuple и вычисляемые типы. Выбор часто задает стиль проекта.

??? question "`any` и `unknown`?"
    `any` отключает проверку операций. `unknown` принимает любое значение, но требует сужения перед использованием, поэтому безопаснее на внешней границе.

??? question "`void` и `never`?"
    `void` означает, что результат функции не используется. `never` означает невозможное значение: функция всегда бросает ошибку или ветка union исчерпана.

??? question "Что такое union и type guard?"
    Union допускает один из типов. Type guard сужает его через `typeof`, `in`, `instanceof`, дискриминант или пользовательскую функцию с предикатом `value is Type`.

??? question "Зачем нужны generics?"
    Они сохраняют связь типов между частями API. Например, `first<T>(items: T[]): T | undefined` возвращает тот же тип элемента, который был во входном массиве.

??? question "Что делают `Partial`, `Pick`, `Omit` и `Record`?"
    Они преобразуют тип: делают поля необязательными, выбирают или исключают ключи, либо строят словарь ключей и значений.

??? question "Почему `as` не валидирует JSON?"
    Assertion влияет только на компилятор и исчезает в JavaScript. Ответ сервера нужно проверить во время выполнения.

??? question "Когда достаточно local state?"
    Когда данные нужны одному небольшому поддереву и не требуют сложной истории переходов или общего кеша.

??? question "Когда Context становится проблемой?"
    Большое часто меняющееся значение перерисовывает всех потребителей и скрывает зависимости. Разделяйте contexts или используйте хранилище с селекторами.

??? question "Как выглядит поток Redux?"
    UI dispatch action, reducer вычисляет новый state, store уведомляет подписчиков, селекторы возвращают нужные части, UI рендерится.

??? question "Почему reducer должен быть чистым?"
    Одинаковый state и action должны давать одинаковый результат без внешних эффектов. Это делает переходы воспроизводимыми и тестируемыми.

??? question "Redux и React Query решают одну задачу?"
    Redux управляет произвольным клиентским состоянием. React Query управляет серверным кешем, его устареванием, запросами и повторной синхронизацией.
