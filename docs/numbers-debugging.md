# 17. Числа, Math и отладка JavaScript

<p class="reading-time">Чтение: 9 минут</p>

Числовая ошибка может появиться из-за строки из формы, неверного округления или особенностей двоичного представления дробей. Отладчик помогает увидеть точный момент расхождения.

!!! abstract "Фокус"
    - **Нужно знать:** преобразование, `NaN`, округление, остаток, breakpoints.
    - **Часто в работе:** `Math`, `Number.isFinite`, Call Stack и Watch.
    - **Достаточно узнавать:** безопасные целые числа, `BigInt`, двоичное устройство IEEE 754.

## Числа и проверка

```js
const amount = Number("12");

Number.isNaN(amount);    // false
Number.isFinite(amount); // true
Number.isInteger(amount); // true
```

`NaN` означает неудачный числовой результат. Он не равен даже самому себе, поэтому используйте `Number.isNaN(value)`, а не `value === NaN`.

```js
NaN === NaN;          // false
Number.isNaN(NaN);    // true
```

Глобальный `isNaN` сначала преобразует значение и может удивить. Метод `Number.isNaN` проверяет без неявного преобразования.

## Основные методы Math

```js
Math.round(4.6); // 5, к ближайшему
Math.floor(4.9); // 4, вниз
Math.ceil(4.1);  // 5, вверх
Math.trunc(4.9); // 4, отбросить дробную часть

Math.min(7, 2, 9); // 2
Math.max(7, 2, 9); // 9
Math.abs(-8);      // 8
```

Случайное целое от `min` до `max` включительно:

```js
function randomInteger(min, max) {
  return Math.floor(Math.random() * (max - min + 1)) + min;
}
```

Оператор `%` возвращает остаток. Он полезен для четности, циклического индекса и группировки.

## Неточные дроби

```js
0.1 + 0.2; // 0.30000000000000004
```

Многие десятичные дроби нельзя точно представить в двоичном формате. Для денег часто считают минимальные единицы целым числом:

```js
const totalKopecks = 1990 + 2990;
const totalRubles = totalKopecks / 100;
```

`toFixed(2)` возвращает строку, а не число.

## Порядок отладки

1. Сформулируйте ожидаемый и фактический результат.
2. Сократите пример до минимального.
3. Поставьте breakpoint до расхождения.
4. Выполняйте код по строкам.
5. Смотрите значения, типы и Call Stack.
6. Исправьте причину и добавьте проверку граничного случая.

В Chrome DevTools полезны:

- Sources для breakpoints и пошагового выполнения;
- Scope для локальных переменных;
- Watch для выбранных выражений;
- Call Stack для цепочки вызовов;
- Console для проверочного выражения, но не как замена отладчику.

```js
function calculatePrice(price, count) {
  debugger;
  return Number(price) * Number(count);
}
```

Инструкция `debugger` останавливает выполнение, если DevTools открыт. Перед публикацией ее обычно удаляют.

!!! warning "Ловушка: исправление симптома"
    Если значение стало `NaN`, не заменяйте его нулем без причины. Найдите первый шаг, на котором корректное число превратилось в неверное значение.

## Как ответить на интервью

> В JavaScript числа обычно имеют тип Number. После пользовательского ввода преобразую значение явно и проверяю через `Number.isFinite` или `Number.isNaN`. Для дробных денег предпочитаю целые минимальные единицы. Ошибку ищу breakpoint-ами, двигаясь от первого неверного состояния, а не добавляя случайные console.log.

## Мини-практика

Исправьте калькулятор цены, который принимает строки, иногда получает пустое значение и округляет сумму. Проверьте ноль, дробную цену, отрицательное количество и нечисловой ввод через breakpoint.
