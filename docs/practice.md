# 50. Мини-задачи для повторения

<p class="reading-time">Практика: 60-90 минут</p>

Выполняйте задачи без копирования готового решения. Сначала сформулируйте входные данные, результат и граничные случаи.

## HTML и CSS

- Сверстайте карточку события: дата, заголовок, место, описание и кнопка регистрации. Используйте семантические элементы.
- Добавьте расписание в таблице с `caption`, заголовками строк и колонок, видео с субтитрами и SVG-иконку.
- Соберите сетку `2 + 1`: большая карточка занимает две колонки, две маленькие стоят справа. На мобильном экране порядок чтения должен быть естественным.
- Создайте форму входа с `label`, проверкой email, подсказками ошибок и видимым фокусом.
- Оформите промоблок с локальным шрифтом, градиентом и декоративным фоном. Проверьте контраст и длинный текст.
- Добавьте переход состояния кнопки и анимацию карточек. Для `prefers-reduced-motion` уберите необязательное движение.
- Соберите каталог на Bootstrap: одна колонка на телефоне, две на `md`, три на `xl`; измените тему через Sass-переменные.
- Перепишите блок старого проекта по БЭМ и вынесите повторяющиеся значения в SCSS.

## Макет и проверка

- До верстки экрана из Figma выпишите контейнер, сетку, отступы, типографику и состояния.
- Сравните результат наложением при одинаковом viewport. Сначала исправьте сетку и шрифт, затем детали.

## JavaScript

- Получите из массива товаров только доступные позиции, увеличьте цену каждой на налог и посчитайте итог.
- Напишите функцию подсчета частоты символов в строке. Пробелы не учитывайте, регистр игнорируйте.
- Реализуйте линейный поиск объекта по `id`. Верните `null`, если объект не найден.
- Напишите валидатор имени, email и возраста. Ошибка каждого поля должна отображаться рядом с ним.
- Рассчитайте итог заказа в копейках, округлите скидку и обработайте нечисловой ввод.
- Найдите ошибку с помощью breakpoint, Scope и Call Stack. Запишите гипотезу и доказательство причины.
- Выбросьте `Error` для некорректных данных и не скрывайте неизвестную ошибку пустым `catch`.

## DOM и события

- Сделайте список задач: добавление, отметка выполнения, удаление. Используйте один обработчик на контейнере списка.
- Создайте модальное окно, которое открывается кнопкой, закрывается по Escape и возвращает фокус на кнопку открытия.
- Дополните слайдер счетчиком и отключайте недоступную кнопку на первом и последнем слайде.

## Асинхронность

- Загрузите пользователей через Fetch API и покажите загрузку, данные, пустой результат и ошибку.
- Сделайте кнопку «Повторить» после ошибки.
- Объясните порядок вывода для кода с `console.log`, `setTimeout` и `Promise.resolve().then(...)`, затем проверьте себя в консоли.

## Браузер, сеть и архитектура JavaScript

- Проследите загрузку страницы в Network и объясните статусы HTML, CSS, JavaScript и запроса данных.
- Сохраните тему в `localStorage`, черновик формы в `sessionStorage` и обработайте поврежденный JSON.
- Спроектируйте REST-маршруты списка задач: методы, URL, тела, успешные ответы и ошибки.
- Разделите приложение на ES-модули API, state, view и entrypoint. Добавьте два маршрута через History API.

## React и TypeScript

- Разделите каталог на компоненты и объясните границу каждого.
- Реализуйте `useDebouncedValue` и отмену устаревшего запроса.
- Опишите состояние запроса через TypeScript union без комбинации взаимоисключающих флагов.
- Типизируйте DOM-форму, React-событие и недоверенный JSON-ответ без слепого `as`.
- Выберите между local state, Context, Redux Toolkit и React Query для четырех разных данных.

## Тесты и производительность

- Протестируйте корзину на добавление, изменение количества и пустое состояние.
- Найдите один лишний рендер через React Profiler и докажите улучшение повторным измерением.
- Разделите тяжелый маршрут через dynamic import и сравните размер начального bundle.

## Backend

- Спроектируйте таблицы заказов и напишите запрос итоговой суммы.
- Создайте PHP endpoint с PDO, валидацией и корректными HTTP-статусами.
- Разделите PHP endpoint на router, controller, service и repository; подключите классы через Composer PSR-4.
- Реализуйте Laravel Form Request, Policy и API Resource для создания заказа.
- Объясните защиту от XSS, CSRF и SQL injection на конкретных границах приложения.

## Работа в IT

- Подготовьте pull request: контекст, изменения, способ проверки, скриншоты состояний и риски.
- Подберите три вакансии, выпишите совпадения и пробелы, адаптируйте заголовок и два пункта резюме.
- Проведите пятиминутную самопрезентацию и подготовьте вопросы о команде, задачах, онбординге и условиях.

## Критерий готовности

- код работает на обычном и граничном сценарии;
- имена объясняют назначение;
- ошибка пользователя не ломает страницу;
- в консоли нет случайных ошибок;
- вы можете объяснить решение без чтения кода построчно.
