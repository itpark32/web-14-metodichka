# Проекты 14 потока

<p class="reading-time">Чтение: 7 минут</p>

Проект полезен для повторения, если вы можете восстановить его архитектуру, объяснить решения и внести изменение без полного переписывания.

## Верстка

### Северяночка

Многостраничная верстка продуктового магазина. В исходниках есть БЭМ, разнесенные CSS-файлы, адаптивные состояния, каталог и работа с графическими ресурсами.

**Попробуйте:** сделайте карточки данными, добавьте корзину и проверьте доступность навигации.

### Clean portfolio

Переработка готового шаблона портфолио: HTML, CSS, адаптация дизайна и очистка зависимостей старого Bootstrap-шаблона.

**Попробуйте:** замените устаревшие плагины нативными API и проведите аудит Lighthouse.

## JavaScript

### Simple Calculator

Калькулятор на DOM-событиях с разбором пользовательского ввода и вычислением результата.

**Попробуйте:** добавьте управление клавиатурой и тест-кейсы для повторного нажатия `=`.

### Угадай число

Генерация случайного числа, счетчик попыток, валидация, состояния победы и поражения, а также перезапуск без перезагрузки.

**Попробуйте:** покажите подсказку «больше» или «меньше» и не допускайте дробные значения.

### Posts App

Небольшое приложение с разделением страниц входа и постов, проверкой авторизации и работой с данными.

**Попробуйте:** вынесите сетевой слой в отдельный модуль и защитите маршрут от прямого открытия.

### Desserts

Vite-приложение с товарами и корзиной. Код разделен на `api`, `products`, `cart`, `spinner` и `error`; данные обслуживает JSON Server.

**Попробуйте:** добавьте optimistic update, пустое состояние и тест расчета итоговой суммы.

### GitHub User Finder

Vite-приложение обращается к GitHub API, выводит профиль пользователя, обрабатывает поиск и переключает цветовую тему.

**Попробуйте:** обработайте лимит API, отменяйте устаревший запрос через `AbortController` и сохраняйте тему.

## React

### Lesson 24

Первое React-приложение на Vite: компоненты, props, список элементов, состояние и обработчики.

**Попробуйте:** добавьте стабильные `key`, форму создания элемента и тест пользовательского сценария.

## Как рассказывать о проекте

1. Какую задачу пользователя решает приложение?
2. Почему вы разделили код именно на эти модули и компоненты?
3. Где хранится состояние и почему?
4. Как обрабатываются загрузка, пустой результат и ошибка?
5. Что вы тестировали и что оптимизировали?
6. Какой следующий технический шаг улучшит проект сильнее всего?
