# 7. Текст, фон, градиенты и эффекты

<p class="reading-time">Чтение: 10 минут</p>

Оформление должно поддерживать иерархию и читаемость. Начинайте с текста и контраста, затем добавляйте фон, границы и эффекты.

!!! abstract "Фокус"
    - **Нужно знать:** шрифт, размер, межстрочный интервал, цвет, фон, граница, тень.
    - **Часто в работе:** `@font-face`, градиенты, `object-fit`, `overflow`.
    - **Достаточно узнавать:** фильтры, маски и сложные режимы смешивания.

## Текст

```css
body {
  color: #17322c;
  font-family: system-ui, sans-serif;
  font-size: 1rem;
  line-height: 1.6;
}

h1 {
  font-size: clamp(2rem, 5vw, 4rem);
  line-height: 1.05;
  letter-spacing: -0.03em;
}
```

`font-size` задает размер, `line-height` влияет на высоту строки, `font-weight` на насыщенность. Длинному тексту обычно нужен межстрочный интервал около `1.5-1.7` и ограниченная длина строки.

## Подключение шрифта

```css
@font-face {
  font-family: "Course Sans";
  src: url("./fonts/course-sans.woff2") format("woff2");
  font-weight: 400 700;
  font-display: swap;
}
```

WOFF2 является основным форматом для веба. `font-display: swap` позволяет сначала показать текст запасным шрифтом. Подключайте только нужные начертания.

## Фон

```css
.hero {
  background-color: #eef5f1;
  background-image: url("hero.webp");
  background-position: center;
  background-size: cover;
  background-repeat: no-repeat;
}
```

`cover` заполняет область с возможной обрезкой. `contain` показывает изображение целиком, но может оставить свободное пространство.

## Градиенты

```css
.banner {
  background:
    linear-gradient(90deg, rgb(16 60 53 / 0.88), rgb(16 60 53 / 0.2)),
    url("banner.webp") center / cover;
}
```

Градиент является изображением CSS, поэтому может быть слоем `background-image`. Первый слой рисуется поверх следующих.

## Границы, радиус и тень

```css
.card {
  border: 1px solid #dbe5df;
  border-radius: 0.75rem;
  box-shadow: 0 0.75rem 2rem rgb(23 76 67 / 0.12);
}
```

Тень не должна заменять всю иерархию. Часто достаточно границы или фона. Сохраняйте одинаковую систему радиусов у однотипных компонентов.

## Изображение внутри блока

```css
.card__image {
  width: 100%;
  aspect-ratio: 16 / 9;
  object-fit: cover;
}
```

`object-fit: cover` сохраняет пропорции и обрезает лишнее. `contain` сохраняет изображение целиком.

## Переполнение

```css
.title {
  overflow: hidden;
  text-overflow: ellipsis;
  white-space: nowrap;
}
```

`overflow` управляет содержимым за границами. Не применяйте `overflow: hidden` ко всей странице, чтобы спрятать ошибку раскладки.

## Контраст и состояния

Текст должен читаться на каждом фоне. Не кодируйте смысл только цветом. Ссылка должна отличаться не только оттенком, а фокус должен быть заметен с клавиатуры.

!!! warning "Ловушка: фон считается декоративным"
    Фоновое изображение не имеет `alt`. Если картинка передает смысл, используйте `img` или `picture`, а не `background-image`.

## Как ответить на интервью

> Сначала настраиваю типографику и контраст, затем фон и декоративные свойства. `cover` заполняет область с обрезкой, `contain` сохраняет изображение целиком. Градиенты являются CSS-изображениями и могут накладываться слоями. Содержательную картинку не помещаю в фон, потому что у фона нет текстовой альтернативы.

## Мини-практика

Оформите карточку курса: локальный шрифт, ограниченный заголовок, изображение 16:9, граница и спокойная тень. Проверьте длинное название, отсутствие изображения и контраст кнопки.
