# Куда двигаться дальше

После основной программы выберите направление, которое помогает решать интересные вам задачи. Не нужно изучать все одновременно: сделайте несколько законченных проектов в одной области и объясните свои решения.

## Frontend глубже

- архитектура больших React-приложений и границы модулей;
- сложные формы и прикладной TypeScript;
- accessibility и design systems;
- performance, профилирование и размер bundle;
- тестирование пользовательских сценариев.

## React frameworks

React строит UI; framework добавляет согласованный способ маршрутизации, загрузки данных, сборки и серверной работы. SSR (server-side rendering) формирует HTML на сервере при запросе. SSG (static site generation) создает страницы заранее во время сборки. После загрузки браузер может подключить интерактивность через hydration.

Современные React-frameworks также предлагают серверную загрузку данных и выполнение серверных операций. Это требует понимания границы между кодом браузера и сервера: секретные значения остаются на сервере, а права проверяются на каждом действии.

Next.js можно изучать как следующий шаг; он не обязателен для базовой программы. Сначала уверенно освойте компоненты, Hooks, routing и API. [SSR и другие стратегии рендеринга](https://reactrouter.com/start/framework/rendering).

## Backend и Full-Stack

Углубляйтесь в PHP, Laravel, SQL и проектирование API. Следующие темы — authentication/authorization, транзакции, конкурирующие изменения, очереди, кеш и наблюдение за ошибками. Начните с небольшого CRUD, в котором есть валидация, права и понятный JSON-контракт.

## Инфраструктура

После уверенной разработки приложений можно изучать Docker, CI/CD, deployment и monitoring. Практическая цель — воспроизводимый запуск, проверка перед публикацией и понимание того, что происходит после релиза.

## Выберите следующий проект

Возьмите каталог, список задач или сервис заметок. Добавьте одну новую сложность: серверный рендеринг, проверяемый API или автоматическую доставку. Сформулируйте критерий результата до начала работы и завершите сценарий вместе с ошибками, тестами и README.
