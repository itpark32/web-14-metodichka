## Как работать с методичкой

На одну тему выделите 15-30 минут. Основной текст читается быстро, остальное время уходит на воспроизведение и практику:

1. Прочитайте главу и закройте вкладку.
2. Объясните идею своими словами за одну минуту.
3. Напишите минимальный пример без копирования.
4. Выполните мини-задачу и проверьте граничный случай.
5. Ответьте на вопросы для собеседования.

!!! tip "Тема повторена"
    Вы можете объяснить механизм, написать короткий пример и назвать частую ошибку. Узнать знакомое слово недостаточно.

## Что подтверждено материалами потока

В папке занятий есть последовательная практика:

- верстка, Git, SCSS, БЭМ, адаптивные макеты «Северяночка» и Clean Portfolio;
- JavaScript-задачи, прототипы, контекст, калькулятор и игра «Угадай число»;
- DOM, формы, авторизация и Posts App;
- Vite, ES-модули, Fetch API, Local Storage, Desserts и GitHub User Finder;
- React 19 на Vite: JSX, компоненты, props, списки и базовое состояние.

Программные главы после этой фактической точки сохранены, потому что вы подтвердили прохождение потоком всей программы. В самих проектах из переданной папки не найдено достаточно исходников, подтверждающих TypeScript, Redux Toolkit, тесты, производительность, трудоустройство и backend.
