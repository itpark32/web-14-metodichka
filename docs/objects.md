# 22. Объекты

<p class="reading-time">Чтение: 9 минут</p>

Объект объединяет свойства одной сущности. Ключ обычно является строкой или символом, значение может иметь любой тип.

!!! abstract "Фокус"
    - **Нужно знать:** доступ к свойствам, проверка наличия, перебор, деструктуризация, ссылки.
    - **Часто в работе:** spread, optional chaining, `JSON.parse` и `JSON.stringify`.
    - **Достаточно узнавать:** дескрипторы, `freeze`, `seal`, ручная работа с прототипом.

## Создание и доступ

```js
const student = {
  name: "Илья",
  age: 17,
  skills: ["HTML", "CSS"],
};

student.name;        // "Илья"
student["age"];     // 17

const key = "skills";
student[key];        // вычисляемое имя
```

Точка удобна для известного корректного имени. Скобки нужны для переменной, пробела, дефиса или другого динамического ключа.

## Наличие свойства

```js
student.city; // undefined

Object.hasOwn(student, "city"); // false
"toString" in student;          // true, учитывает цепочку прототипов
```

Проверка `student.city === undefined` не отличает отсутствующее свойство от существующего свойства со значением `undefined`. Для собственного свойства используйте `Object.hasOwn`.

## Перебор

```js
Object.keys(student);    // массив ключей
Object.values(student);  // массив значений
Object.entries(student); // массив пар [ключ, значение]

for (const [key, value] of Object.entries(student)) {
  console.log(key, value);
}
```

## Деструктуризация и значения по умолчанию

```js
const { name, age, city = "Брянск" } = student;

function printStudent({ name, skills = [] }) {
  console.log(`${name}: ${skills.join(", ")}`);
}
```

Значение по умолчанию срабатывает при `undefined`, но не при `null`.

## Ссылки и сравнение

```js
const first = { id: 1 };
const second = { id: 1 };
const same = first;

first === second; // false
first === same;   // true
```

Объекты сравниваются по идентичности ссылки, а не по содержимому.

```js
const profile = { name: "Лена" };
const alias = profile;
alias.name = "Елена";

console.log(profile.name); // "Елена"
```

Обе переменные ссылаются на один объект.

## Поверхностная копия и обновление

```js
const updated = {
  ...student,
  age: 18,
};
```

Порядок важен: более позднее свойство перезаписывает более раннее. Spread и `Object.assign` копируют только верхний уровень.

```js
const course = { title: "Web", author: { name: "Сергей" } };
const copy = { ...course };
copy.author.name = "Анна";

console.log(course.author.name); // "Анна"
```

Для поддерживаемых типов глубокую копию можно сделать `structuredClone(course)`. JSON-прием теряет `undefined`, методы и некоторые специальные значения, поэтому не является универсальным клонированием.

## Безопасный доступ

```js
const city = student.address?.city ?? "Город не указан";
```

`?.` останавливает цепочку при `null` или `undefined`. `??` подставляет запасное значение только для `null` и `undefined`, поэтому не заменяет допустимые `0`, `false` и пустую строку.

## JSON

```js
const json = JSON.stringify(student);
const restored = JSON.parse(json);
```

JSON является текстовым форматом обмена данными. `JSON.parse` может выбросить ошибку на некорректной строке, поэтому внешние данные иногда нужно разбирать внутри `try`/`catch`.

## Как ответить на интервью

> Объект хранит пары ключ-значение и используется для описания сущности. Доступ через точку подходит известному ключу, скобки нужны динамическому. Объекты сравниваются по ссылке. Spread создает поверхностную копию, поэтому вложенные объекты могут остаться общими. Наличие собственного свойства проверяю через `Object.hasOwn`.

## Мини-практика

Напишите функцию `updateUser(user, changes)`, которая возвращает новый объект без изменения исходного. Затем добавьте вложенный `address` и покажите, почему одного spread недостаточно для независимого обновления города.
