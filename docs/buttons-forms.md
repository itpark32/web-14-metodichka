# 4. Кнопки и формы

<p class="reading-time">Чтение: 10 минут</p>

Кнопка кажется простым элементом, но именно здесь часто путают действие, переход, отправку формы и доступность.

!!! abstract "Фокус"
    - **Нужно знать:** `button`, его `type`, отличие от ссылки, `label`, `name`, отправка формы.
    - **Часто в работе:** `disabled`, `autocomplete`, `required`, `FormData`.
    - **Достаточно узнавать:** `formaction`, `formmethod` и другие атрибуты переопределения формы.

## Как можно сверстать кнопку

### Нативная кнопка

```html
<button type="button">Открыть фильтры</button>
```

Используйте для действия без перехода: открыть окно, добавить товар, переключить состояние, запустить расчет.

### Кнопка отправки формы

```html
<button type="submit">Создать аккаунт</button>
```

Используйте внутри формы, когда действие отправляет ее данные. Форма также может отправиться по Enter.

### Ссылка в виде кнопки

```html
<a class="button" href="/catalog">Перейти в каталог</a>
```

Если меняется адрес, семантически это ссылка, даже если CSS делает ее похожей на кнопку.

### `input` с типом кнопки

```html
<input type="submit" value="Отправить">
```

Такой вариант работает, но `button` гибче: внутрь можно поместить текст и иконку, а подпись не смешивается со значением поля.

!!! warning "Не делайте кнопку из div"
    `div` не получает фокус с клавиатуры, не активируется клавишами Enter и Space и не сообщает роль скринридеру. Исправлять все это вручную сложнее, чем использовать `button`.

## Главные атрибуты `button`

| Атрибут | Что делает | Когда нужен |
|---|---|---|
| `type="button"` | Обычное действие | Кнопка интерфейса внутри или вне формы |
| `type="submit"` | Отправляет форму | Подтверждение данных |
| `type="reset"` | Возвращает исходные значения | Редко, поведение может удивить пользователя |
| `disabled` | Отключает кнопку | Действие временно недоступно |
| `name` и `value` | Добавляет пару в данные формы | Серверу важно, какая кнопка нажата |
| `form` | Связывает кнопку с формой по `id` | Кнопка расположена вне формы |

У `button` внутри формы тип по умолчанию обычно `submit`. Поэтому у кнопок, которые не должны отправлять форму, всегда указывайте `type="button"`.

## Состояния кнопки

```css
.button {
  border: 0;
  border-radius: 0.5rem;
  padding: 0.75rem 1rem;
  color: #f5fbf8;
  background: #174c43;
  cursor: pointer;
}

.button:hover { background: #103c35; }
.button:focus-visible { outline: 3px solid #c44b2b; outline-offset: 3px; }
.button:active { transform: translateY(1px); }
.button:disabled { cursor: not-allowed; opacity: 0.55; }
```

Не убирайте `outline`, если не добавили заметную замену. Цвет не должен быть единственным признаком состояния.

## Поле, подпись и данные

```html
<form id="signup-form">
  <label for="email">Электронная почта</label>
  <input id="email" name="email" type="email" autocomplete="email" required>
  <button type="submit">Зарегистрироваться</button>
</form>
```

- `label` называет поле и увеличивает область нажатия;
- `id` связывает поле с `for`;
- `name` задает ключ при отправке данных;
- `type` сообщает формат и влияет на мобильную клавиатуру;
- `autocomplete` помогает браузеру подставить знакомое значение;
- `required` включает базовую браузерную проверку.

`placeholder` показывает пример, но не заменяет постоянную подпись. Он исчезает после ввода и часто имеет слабый контраст.

## Обработка отправки

```js
const form = document.querySelector("#signup-form");

form.addEventListener("submit", (event) => {
  event.preventDefault();
  const data = new FormData(form);
  console.log(data.get("email"));
});
```

Слушайте `submit` у формы, а не только `click` у кнопки. Так код работает и при отправке клавишей Enter. `preventDefault()` отменяет стандартный переход, но не останавливает всплытие события.

!!! warning "Неожиданное поведение"
    Отключенное поле и отключенная кнопка не участвуют в обычной отправке формы. Если значение должно попасть в данные, не используйте `disabled` как способ только визуально запретить редактирование.

## Как ответить на интервью

> Для действия в интерфейсе использую `button`, для навигации использую `a` с `href`. В форме явно задаю кнопке `type`, потому что значение по умолчанию может отправить форму. Поля связываю с `label`, даю им `name` и обрабатываю событие `submit`, чтобы поддержать клавиатуру.

Если спросят о доступной кастомной кнопке, лучший первый ответ: использовать нативный `button`. ARIA дополняет семантику, но не должна заменять подходящий HTML-элемент.
