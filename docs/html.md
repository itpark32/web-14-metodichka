# 1. Структура HTML

<p class="reading-time">Чтение: 5 минут</p>

HTML описывает смысл и структуру страницы. Браузер читает разметку и строит дерево элементов, с которым затем работают CSS и JavaScript.

## Каркас документа

```html
<!doctype html>
<html lang="ru">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1">
    <title>Название страницы</title>
    <link rel="stylesheet" href="style.css">
    <script src="script.js" defer></script>
  </head>
  <body>
    <header>...</header>
    <main>...</main>
    <footer>...</footer>
  </body>
</html>
```

- `head` хранит служебные данные, подключения и заголовок вкладки.
- `body` содержит видимое содержимое.
- `defer` запускает внешний скрипт после разбора HTML и сохраняет порядок скриптов.
- `lang` помогает браузеру и скринридеру выбрать язык.

## Семантика

Выбирайте тег по назначению, а не по внешнему виду:

- `header`, `nav`, `main`, `section`, `article`, `aside`, `footer` задают области страницы;
- `h1`-`h6` строят иерархию заголовков;
- `a` выполняет переход, `button` запускает действие;
- `strong` отмечает важность, `em` задает смысловое ударение;
- `img` требует полезный `alt`, если изображение несет информацию.

```html
<article class="product-card">
  <h2>Кофе арабика</h2>
  <img src="coffee.jpg" alt="Чашка кофе из зерен арабики">
  <p>Мягкий вкус с ореховыми нотами.</p>
  <button type="button">Добавить в корзину</button>
</article>
```

## Пути и ссылки

`./images/photo.jpg` считается от текущего файла, `../` поднимает на уровень выше. Абсолютный URL начинается с протокола и домена. Для перехода внутри страницы используйте `href="#contacts"` и элемент с `id="contacts"`.

!!! warning "Частая ошибка"
    Не превращайте `div` в кнопку только из-за удобства стилизации. У настоящей кнопки уже есть клавиатурное управление, фокус и понятная роль.

## Мини-практика

Сверстайте карточку статьи с заголовком, датой, изображением, текстом и ссылкой. Затем проверьте документ [валидатором W3C](https://validator.w3.org/).
