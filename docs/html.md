# 2. Структура и семантика HTML

<p class="reading-time">Чтение: 9 минут</p>

HTML описывает структуру и смысл документа. Браузер разбирает разметку, строит DOM, а затем применяет CSS и подключает поведение JavaScript.

!!! abstract "Фокус"
    - **Нужно знать:** каркас документа, семантика, заголовки, ссылки, изображения.
    - **Часто в работе:** `data-*`, `defer`, относительные пути.
    - **Достаточно узнавать:** редкие семантические элементы и старые режимы HTML.

## Каркас документа

```html
<!doctype html>
<html lang="ru">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1">
    <title>Каталог курсов</title>
    <meta name="description" content="Курсы веб-разработки">
    <link rel="stylesheet" href="style.css">
    <script src="script.js" defer></script>
  </head>
  <body>
    <header>...</header>
    <main>...</main>
    <footer>...</footer>
  </body>
</html>
```

- `<!doctype html>` включает стандартный режим браузера.
- `lang` сообщает язык документа браузеру, переводчику и скринридеру.
- `charset` задает кодировку до появления русского текста.
- `viewport` нужен для корректной ширины страницы на мобильном устройстве.
- `title` называет вкладку и используется поисковыми системами.
- `defer` загружает внешний скрипт параллельно, но выполняет после разбора HTML с сохранением порядка.

## Семантика вместо универсального `div`

Семантический тег сообщает роль содержимого. Он не выбирается по внешнему виду.

```html
<article class="course-card">
  <header>
    <h2>Основы JavaScript</h2>
    <p>Практический курс</p>
  </header>
  <p>Переменные, функции, DOM и запросы к API.</p>
  <a href="/courses/javascript">Открыть курс</a>
</article>
```

Основные ориентиры:

- `main` содержит главное содержимое страницы и обычно встречается один раз;
- `nav` оборачивает значимую группу навигационных ссылок;
- `section` объединяет тематический раздел, чаще всего с заголовком;
- `article` подходит материалу, который понятен отдельно: карточке статьи, новости, посту;
- `aside` содержит дополнение к основному материалу;
- `header` и `footer` могут относиться ко всей странице или к отдельному разделу.

!!! warning "Ловушка: section вместо div"
    `section` не является красивым названием для любого контейнера. Если у блока нет самостоятельной темы и заголовка, часто достаточно `div`.

## Иерархия заголовков

`h1` обозначает главный заголовок страницы. Следующие уровни отражают вложенность содержания, а не желаемый размер шрифта.

```html
<main>
  <h1>Каталог курсов</h1>
  <section>
    <h2>Веб-разработка</h2>
    <article><h3>JavaScript</h3></article>
  </section>
</main>
```

Внешний вид заголовка меняйте CSS. Не перескакивайте с `h2` на `h5` только ради меньшего шрифта.

## Ссылка или действие

```html
<a href="/profile">Открыть профиль</a>
<button type="button">Удалить фотографию</button>
```

Ссылка меняет адрес или переводит к ресурсу. Кнопка запускает действие в текущем интерфейсе. Настоящие элементы уже поддерживают клавиатуру, фокус и понятную роль.

## Изображения и `alt`

```html
<img src="student.webp"
     alt="Студент показывает макет интернет-магазина"
     width="960" height="640" loading="lazy">
```

Полезный `alt` передает смысл изображения в контексте. Для декоративной картинки используйте `alt=""`. Не начинайте описание со слов «картинка» или «изображение»: скринридер уже объявит тип элемента. `width` и `height` помогают браузеру заранее зарезервировать место.

## Глобальные и `data-*` атрибуты

`id`, `class`, `title`, `hidden`, `lang`, `tabindex` и `data-*` применимы ко многим элементам. Пользовательские данные храните в `data-*`:

```html
<button type="button" data-product-id="42">В корзину</button>
```

```js
const button = document.querySelector("[data-product-id]");
console.log(button.dataset.productId); // "42"
```

Значение в `dataset` читается как строка. Для числа потребуется явное преобразование.

## Как ответить на интервью

> HTML представляет структуру и смысл документа. Я выбираю элементы по назначению, сохраняю последовательную иерархию заголовков и использую нативные ссылки, кнопки и поля. Это делает разметку понятнее, доступнее и удобнее для браузера, поиска и JavaScript.

Короткий ответ усиливается примером. Для семантики назовите `nav`, `main`, `article`; для доступности покажите `alt`, `label` или нативную кнопку.
