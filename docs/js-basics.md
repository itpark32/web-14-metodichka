# 8. JavaScript: данные и условия

<p class="reading-time">Чтение: 7 минут</p>

JavaScript добавляет странице данные, вычисления и поведение. Начинайте с точной модели типов и явных преобразований.

## Переменные

```js
const courseName = "Веб-разработка";
let completedLessons = 28;
completedLessons += 1;
```

Используйте `const`, если не планируете переназначать переменную. `let` нужен для меняющегося значения. `var` имеет функциональную область видимости и допускает повторное объявление, поэтому в новом коде обычно не нужен.

`const` запрещает переназначить переменную, но не делает объект неизменяемым:

```js
const user = { name: "Алекс" };
user.name = "Маша"; // допустимо
```

## Типы

Семь примитивов: `string`, `number`, `bigint`, `boolean`, `undefined`, `symbol`, `null`. Отдельно стоит объектный тип: объекты, массивы и функции.

```js
typeof "15";       // "string"
typeof 15;         // "number"
typeof true;       // "boolean"
typeof undefined;  // "undefined"
typeof null;       // "object", историческая особенность
Array.isArray([]); // true
```

## Преобразование и сравнение

```js
const value = "15";
Number(value);  // 15
String(15);     // "15"
Boolean(15);    // true

15 === "15";   // false
15 == "15";    // true из-за неявного преобразования
```

Предпочитайте `===` и `!==`. Они не приводят операнды к общему типу.

## Условия и ложные значения

```js
if (age >= 16 && hasAccess) {
  console.log("Доступ открыт");
} else {
  console.log("Доступ закрыт");
}
```

В условии ложными считаются `false`, `0`, `-0`, `0n`, `""`, `null`, `undefined` и `NaN`. Пустые массив и объект истинны.

!!! warning "Проверяйте ввод"
    Значение поля формы и результат `prompt()` являются строками. Преобразуйте их перед арифметикой и проверьте через `Number.isNaN()`.

## Мини-практика

Напишите проверку значения поля возраста. Допускаются целые числа от 16 до 100. Для пустой строки, `NaN` и значения вне диапазона выведите разные сообщения.
