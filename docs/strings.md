# 20. Строки

<p class="reading-time">Чтение: 10 минут</p>

Строка хранит текст. Строки неизменяемы: метод не переписывает исходное значение, а возвращает новое.

!!! abstract "Фокус"
    - **Нужно знать:** `length`, индекс, `includes`, `slice`, `trim`, `replace`, `split`.
    - **Часто в работе:** `startsWith`, `endsWith`, `replaceAll`, шаблонные строки.
    - **Достаточно узнавать:** `padStart`, `localeCompare`, особенности Unicode.

## Создание и доступ

```js
const name = "Марина";
const message = `Привет, ${name}!`;

message.length; // 15
message[0];     // "П"
message.at(-1); // "!"
```

Шаблонная строка в обратных кавычках подставляет выражения и может занимать несколько строк. Индекс начинается с нуля. `at(-1)` удобно получает последний символ.

```js
const word = "код";
word[0] = "х";
console.log(word); // "код"
```

Изменение символа по индексу не сработает. Создайте новую строку.

## Проверка содержимого

```js
const title = "Курс JavaScript";

title.includes("Java");     // true
title.startsWith("Курс");   // true
title.endsWith("Script");   // true
title.indexOf("Java");      // 5
title.indexOf("Python");    // -1
```

Методы чувствительны к регистру. Для поиска без учета регистра сначала приведите обе стороны к одному регистру:

```js
const query = "javascript";
title.toLowerCase().includes(query.toLowerCase());
```

## Извлечение части

```js
const value = "frontend";

value.slice(0, 5);  // "front"
value.slice(5);     // "end"
value.slice(-3);    // "end"
```

Начальная граница входит в результат, конечная не входит. `slice` поддерживает отрицательные индексы. Этого метода обычно достаточно, поэтому отдельно заучивать старый `substr` не нужно.

## Очистка и регистр

```js
const raw = "  user@example.com  ";
const email = raw.trim().toLowerCase();
```

- `trim()` убирает пробельные символы по краям;
- `trimStart()` и `trimEnd()` работают только с одной стороной;
- `toLowerCase()` и `toUpperCase()` возвращают строку в выбранном регистре.

`trim()` не удаляет пробелы внутри строки. Для сложной очистки пригодятся регулярные выражения.

## Замена

```js
const text = "кот, кот, кот";

text.replace("кот", "код");    // "код, кот, кот"
text.replaceAll("кот", "код"); // "код, код, код"
text.replace(/кот/g, "код");    // "код, код, код"
```

!!! warning "Ловушка: replace меняет только первое совпадение"
    Со строкой поиска `replace()` заменяет первое совпадение. Для всех совпадений используйте `replaceAll()` или регулярное выражение с флагом `g`.

## Строка и массив

```js
const tags = "html, css, javascript"
  .split(",")
  .map(tag => tag.trim());

tags;             // ["html", "css", "javascript"]
tags.join(" / "); // "html / css / javascript"
```

`split` разбивает строку и возвращает массив. `join` вызывается у массива и собирает строку.

!!! warning "Ловушка: split без разделителя"
    `"abc".split()` вернет `["abc"]`, а `"abc".split("")` вернет `["a", "b", "c"]`. Это разные вызовы.

## Преобразование в число

```js
Number("42");       // 42
Number("");         // 0
Number("42px");     // NaN
parseInt("42px", 10); // 42
```

`Number` требует, чтобы вся непустая строка представляла число. `parseInt` читает целое число с начала строки до первого неподходящего символа. После преобразования проверяйте `Number.isNaN(value)` или требуемый диапазон.

## Особенность Unicode

```js
"🙂".length; // 2
```

JavaScript считает UTF-16 кодовые единицы, поэтому визуальный символ не всегда равен одному индексу. Для обычных учебных задач это редко мешает, но нельзя считать `length` надежным количеством пользовательских символов для любого языка и emoji.

## Как ответить на интервью

> Строки в JavaScript неизменяемы: методы возвращают новое значение. Для проверки использую `includes` или `startsWith`, для части строки `slice`, для очистки `trim`, для замены `replace` или `replaceAll`, для разбиения `split`. Учитываю регистр, тип результата и то, что `replace` без глобального режима меняет первое совпадение.

## Мини-практика

Напишите `normalizeTags(value)`, которая принимает строку `"  HTML, css, JavaScript, css "`, удаляет пробелы, приводит теги к нижнему регистру и возвращает массив без пустых значений. Дополнительный уровень: убрать дубликаты.
