# 11. Функции и область видимости

<p class="reading-time">Чтение: 8 минут</p>

Функция объединяет действие под именем. Хорошая функция получает зависимости через параметры, возвращает результат и решает одну понятную задачу.

## Параметры и `return`

```js
function calculateTotal(price, amount = 1) {
  return price * amount;
}

const total = calculateTotal(450, 2);
```

Параметры объявлены в функции, аргументы передаются при вызове. `return` немедленно завершает функцию и возвращает значение. `console.log()` только выводит данные.

## Формы объявления

```js
function declaration() {}

const expression = function () {};

const arrow = (value) => value * 2;
```

Function Declaration доступна до строки объявления благодаря подъему. Function Expression и стрелочная функция становятся доступны после инициализации переменной. У стрелочной функции нет собственного `this` и `arguments`.

## Область видимости и замыкание

```js
function createCounter() {
  let count = 0;

  return function () {
    count += 1;
    return count;
  };
}

const next = createCounter();
next(); // 1
next(); // 2
```

Внутренняя функция сохраняет доступ к переменным внешней функции даже после завершения внешнего вызова. Это замыкание.

## `this`

Для обычной функции значение `this` зависит от способа вызова:

```js
const user = {
  name: "Маша",
  sayName() {
    return this.name;
  },
};

user.sayName(); // "Маша"
```

`bind` создает функцию с закрепленным `this`. Стрелочная функция берет `this` из внешней области и не подходит как универсальная замена методу.

## Прототип

Объект может наследовать свойства по цепочке прототипов. Методы конструктора часто размещают в `Constructor.prototype`, чтобы экземпляры использовали одну функцию, а не создавали копию для каждого объекта.

## Мини-практика

Создайте `createAccumulator(start)`, который возвращает функцию. Каждый вызов внутренней функции принимает число, прибавляет его к сохраненной сумме и возвращает новый результат.
