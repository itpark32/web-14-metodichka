# 8. Flexbox и Grid

<p class="reading-time">Чтение: 9 минут</p>

Flexbox раскладывает элементы преимущественно по одной оси. Grid управляет строками и колонками одновременно. Их нормально использовать вместе.

!!! abstract "Фокус"
    - **Нужно знать:** оси Flexbox, `gap`, перенос, `grid-template-columns`, `fr`, `minmax`.
    - **Часто в работе:** `flex` как сокращение, `auto-fit`, `span`.
    - **Достаточно узнавать:** ручное размещение по именованным grid-линиям.

## Flexbox

```css
.header {
  display: flex;
  align-items: center;
  justify-content: space-between;
  gap: 24px;
}
```

Главная ось задается `flex-direction`. `justify-content` работает вдоль главной оси, `align-items` вдоль поперечной. `gap` задает промежуток без внешних отступов у дочерних элементов.

```css
.nav {
  display: flex;
  flex-wrap: wrap;
  gap: 12px 20px;
}

.nav__item {
  flex: 0 1 auto;
}
```

`flex` сокращает `flex-grow`, `flex-shrink` и `flex-basis`.

```css
.nav__search {
  flex: 1 1 18rem;
}
```

Здесь элемент может расти, может сжиматься и начинает расчет от базового размера `18rem`. Частая причина переполнения: у flex-элемента с длинным текстом остается `min-width: auto`. В таком случае проверьте `min-width: 0`.

## Grid

```css
.catalog {
  display: grid;
  grid-template-columns: repeat(3, minmax(0, 1fr));
  gap: 24px;
}

.catalog__featured {
  grid-column: span 2;
}
```

Сетка без жесткого числа колонок:

```css
.catalog {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(min(100%, 16rem), 1fr));
  gap: 1.5rem;
}
```

`auto-fit` создает столько колонок, сколько помещается. Внутренний `min(100%, 16rem)` не дает минимальной ширине вытолкнуть сетку за узкий экран.

Grid удобен, когда элементы должны выравниваться и по горизонтали, и по вертикали. `fr` делит свободное место, `minmax()` задает границы размера, `span` позволяет занять несколько дорожек.

## Как выбрать

| Задача | Инструмент |
|---|---|
| Навигация, строка кнопок, выравнивание иконки и текста | Flexbox |
| Каталог, галерея, макет из строк и колонок | Grid |
| Внутри карточки | Часто Flexbox |
| Сетка карточек | Часто Grid |

!!! warning "Ловушка с направлениями"
    `justify-content` не всегда означает горизонтальное выравнивание. Оно работает по главной оси, а направление главной оси меняет `flex-direction`.

## Как ответить на интервью

> Flexbox решает в основном одномерную раскладку по главной и поперечной осям. Grid задает строки и колонки одновременно. Для навигации и содержимого карточки я чаще выбираю Flexbox, для каталога и общей сетки Grid. Их можно и нужно сочетать.
