# 11. Bootstrap: сетка и готовые компоненты

<p class="reading-time">Чтение: 9 минут</p>

Bootstrap ускоряет типовую адаптивную верстку. Он дает сетку, утилиты и готовые компоненты, но не отменяет знание HTML, CSS и доступности.

!!! abstract "Фокус"
    - **Нужно знать:** container, grid, breakpoints, utilities и компоненты.
    - **Часто в работе:** настройка темы, адаптивные классы, подключение JavaScript-компонентов.
    - **Достаточно узнавать:** полный список классов и Sass-переменных.

## Контейнер и сетка

```html
<div class="container">
  <div class="row g-4">
    <div class="col-12 col-md-6 col-xl-4">...</div>
    <div class="col-12 col-md-6 col-xl-4">...</div>
  </div>
</div>
```

`container` ограничивает ширину, `row` создает строку сетки, `col-*` описывает ширину колонки на разных контрольных точках. Bootstrap использует mobile first: класс без префикса действует всегда, `md` и `xl` добавляют правила с соответствующей ширины.

## Утилиты

```html
<article class="d-flex flex-column gap-3 p-4 rounded shadow-sm">
  <h2 class="fs-4 mb-0">Товар недели</h2>
  <button class="btn btn-primary align-self-start">В корзину</button>
</article>
```

Утилиты удобны для небольших правил: display, отступов, размеров, выравнивания и типографики. Если набор классов начинает скрывать смысл компонента или постоянно повторяется, вынесите правило в собственный класс.

## Компоненты и JavaScript

Кнопки и карточки работают на CSS. Модальное окно, раскрывающееся меню и tooltip требуют JavaScript Bootstrap или собственного поведения.

```html
<button
  class="btn btn-success"
  data-bs-toggle="modal"
  data-bs-target="#orderModal"
>
  Оформить заказ
</button>
```

При подключении готового компонента проверьте документацию своей версии. Разметка, data-атрибуты и доступность могут отличаться между версиями.

## Настройка

Для небольшого проекта можно переопределить CSS-переменные и добавить собственные классы после Bootstrap. В SCSS-проекте переменные темы задают до импорта исходников Bootstrap, чтобы не дублировать множество правил.

```scss
$primary: #1f6f5f;
$border-radius: 0.75rem;

@import "bootstrap/scss/bootstrap";
```

Не используйте `!important` как основной способ борьбы со стилями фреймворка. Сначала проверьте порядок подключения, специфичность и предусмотренные точки настройки.

## Доступность и лишний код

Готовый внешний вид не гарантирует доступность. Проверьте подписи полей, порядок фокуса, клавиатуру и контраст. Подключайте только нужные JavaScript-модули, если сборка позволяет это сделать.

!!! warning "Ловушка: копирование без понимания"
    Класс из примера документации решает конкретную задачу. Если не понимать сетку, breakpoints и DOM-структуру компонента, исправление адаптивности превращается в цепочку случайных переопределений.

## Как ответить на интервью

> Bootstrap предоставляет адаптивную сетку, утилиты и готовые компоненты. Я использую его для ускорения типовой верстки, но сохраняю семантический HTML, проверяю доступность и настраиваю тему через предусмотренные переменные, а не набор случайных `!important`.

## Мини-практика
